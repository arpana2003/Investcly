
# InvestCly 💰

InvestCly is a full-stack investment and personal finance management platform designed to help users make informed financial decisions. It provides financial news, investment-related content, educational resources, and interactive calculators through a modern and responsive web interface.

## 🚀 Features

- 📰 **Financial News & Articles**
  - Browse financial news and investment-related articles.
  - Categorized content for easier navigation.
  - Featured and headline articles.

- 📊 **Financial Calculators**
  - Loan Calculator
  - Home Loan Calculator
  - Car Loan Calculator
  - Investment Calculator
  - Budget Planner
  - Fixed Deposit Calculator
  - Credit Score Estimator
  - Insurance Calculator
  - Net Worth Calculator
  - Revenue Calculator

- 🎓 **Finance Academy**
  - Educational content related to finance and investments.
  - Helps users improve their financial knowledge.

- 📈 **Market & Commodity Information**
  - Access commodity-related information.
  - Explore financial and investment-related data.

- 🔐 **Authentication & Authorization**
  - User registration and login.
  - JWT-based authentication.
  - Google OAuth authentication.
  - Forgot password and password reset functionality.

- 👨‍💼 **Admin Dashboard**
  - Create and manage articles.
  - Edit existing articles.
  - Delete articles.
  - Upload article images.
  - Manage categorized content.

- ☁️ **Cloud Image Storage**
  - Image uploads using Cloudinary.

- 📱 **Responsive UI**
  - Responsive design for desktop, tablet, and mobile devices.
  - Dark/light theme support.
